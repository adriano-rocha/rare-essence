\# Skill 02: Estratégia de Testes &amp; Test Harness ## Objetivo Manter uma suíte de testes ultrarrápida, determinística e com alta cobertura de regras críticas do e-commerce. ## Pirâmide de Testes (Harness) 1\. \*\*Unit Harness (Domínio &amp; Casos de Uso):\*\* - Testes puros sem banco de dados e sem chamadas HTTP. - Cobertura obrigatória: Value Object \`Money\`, calculadoras de frete grátis (subtotal &gt;= R$ 350,00 / 35000 centavos), desconto Pix (5%), cupom e máquina de estados do Pedido. 2\. \*\*Contract Harness (Ports &amp; Adapters):\*\* - Garantir que os Fakes em memória (ex.: \`FakePagamentoGateway\`, \`FakeFreteGateway\`) e os Adapters reais (Mercado Pago, Melhor Envio) respeitem rigorosamente o mesmo contrato (Princípio de Substituição de Liskov - LSP). 3\. \*\*Integration Harness:\*\* - Testar repositórios (Prisma) e transações atômicas de estoque (reserva vs saldo disponível) contra banco PostgreSQL real via contêiner. 4\. \*\*E2E Harness (Playwright):\*\* - Validar a jornada crítica do usuário: Vitrine -&gt; PDP -&gt; Slide-over Cart -&gt; Checkout Convidado -&gt; Tela de Confirmação com QR Code Pix.
