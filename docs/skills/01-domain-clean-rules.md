\# Skill 01: Regras Estritas de Domínio (Clean Domain) ## Objetivo Garantir o isolamento absoluto da camada de domínio em \`src/modules/\*/domain\` e em \`src/shared/\`, respeitando a Clean Architecture e os princípios do DDD. ## Diretrizes Fundamentais 1\. \*\*Isolamento de Domínio (RNF-005):\*\* O código dentro de \`domain/\` é TypeScript puro. É PROIBIDO importar Prisma, React, Next.js, Zod ou qualquer biblioteca de terceiros na camada de domínio. 2\. \*\*Manipulação de Moeda (RNF-001):\*\* Todos os valores monetários devem ser representados e operados em centavos de Real (números inteiros) usando o Value Object \`Money\`. É PROIBIDO o uso de números de ponto flutuante (\`float\`) para preços. 3\. \*\*Tratamento de Erros Sem Exceções:\*\* Não utilize \`throw\` para erros previstos de regra de negócio.
